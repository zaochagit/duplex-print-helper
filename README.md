# 手动双面打印助手

给「只能手动双面」的喷墨打印机（实测 Brother DCP-T420W）用的自动双面打印工具。
支持 **PDF** 和 **Word**（`.doc` / `.docx` / `.docm` / `.rtf`，自动经本机 Word 转 PDF，版式与 Word 打印一致）。

## 为什么需要它

手动双面打印的麻烦不在「翻面」，而在「配对」：先打哪几页、翻回去后顺序怎么对得上。
本工具按一套经过验证的规则自动算好两轮打印计划，你只需要：

> 放纸 → 等第一轮 → **整叠原样放回** → 确认 → 第二轮

出来的成品第 1 页就在最上面，**零整理**。

## 核心规则（务必看一眼）

喷墨纸盒是「打印面朝下装入」，实际打在纸的**朝下一面**，出纸后字面朝上。因此：

- ⚠️ **第一轮打完，整叠纸【原样】放回纸盒，千万别翻面！**
  翻面会让第二遍直接印在已经印字的那一面上，整叠报废。
- 放回时不翻面，取纸顺序自然倒过来，所以**第二轮用降序**打印，让第 1 页最后打、压在最上面。
- **总页数奇数**时，第一轮末尾会自动多打一张空白页（把末页那张纸先走一遍），两轮张数相等，末页正好是第 1 页。
- ⚠️ **打印机首选项里的「逆序打印 / 反向打印」必须关闭**：它会在驱动层把程序发的页序整个反转（如 `7,5,3,1` → `1,3,5,7`），导致正反面配对错乱、成品顺序颠倒。此项和上面的「立即开始打印」是两个不同的开关。
  **注意：本工具不会读取、也不会自动关闭这个开关**——它藏在打印机驱动的私有设置里，不同驱动位置不一样、无法通用读取，所以得由你手动确认它是关着的。拿不准就跑一次「校准测试」用实物验证（见下）。

## 下载与运行（绿色版，无需安装）

提供「绿色版」：一个文件夹，解压到任意位置（U盘、D盘都行）直接双击里面的 `双面打印助手.exe` 即可，
**不用安装、不写注册表**。打印机选择等设置保存在系统目录 `%APPDATA%\duplex_print\config.json`，
所以**只在第一次运行时选一次打印机，之后都记住**，不会因为放在不同位置而重设。

> 绿色版在 [Releases 下载](https://github.com/zaochagit/duplex-print-helper/releases/download/v1.0/duplex-print-helper-green.zip)（`duplex-print-helper-green.zip`，约 38MB）。解压后整个文件夹带走即可。

### 图形界面

双击 `双面打印助手.exe`：

1. 首次启动会让你选打印机，选定后记住，以后不再问；
2. 文件路径可以「输入框粘贴 / 点浏览 / 直接把文件拖进窗口」；
3. 点「开始打印」→ 打完第一轮弹确认框（防误操作）→ 确认后打第二轮；
4. 「校准测试」按钮用 2 张纸验证你机器的进出纸机制。

### 命令行 / 拖拽

有 Python 环境时，把 PDF 或 Word 拖到 `duplex.bat` 上即可。或：

```bat
python duplex_print.py 文件.pdf
python duplex_print.py --calibrate   # 校准
python duplex_print.py --dry-run     # 只看计划不打印
```

## 首次使用：校准（建议）

```bat
python duplex_print.py --calibrate
```

打完检查两件事：

1. 有没有「字叠字」（某面被印了两次）→ 有说明放回时把纸叠翻面了，重打；
2. 第 1 页的背面是不是第 2 页 → 对就正常。

本工具的默认顺序已按 Brother DCP-T420W 实测机制调好，多数机器直接可用。

## ⚠️ 驱动与兼容性提醒

- **打印机驱动建议用 Brother 原厂驱动**。有机器上这台打印机是以「Microsoft IPP Class Driver」（系统通用类驱动）形式连上的：能打，但「双面 / 逆序打印」等高级项不是 Brother 原生，行为不如原厂驱动可预测。想让手动双面更稳，去 Brother 官网下载 DCP-T420W 原厂驱动装一下即可。
- **「逆序打印 / 反向打印」请保持关闭**：如上一节所述，工具无法替你读或关它，只能靠你手动在「打印机首选项 → 高级」里确认。不确定时跑「校准测试」用实物验证最稳妥。
- **采用前台直驱（立即开始打印）**：打印期间工具会临时把该打印机设为「直接打印」，避免大体积扫描 PDF 在后台排队等半天；打印完自动还原，不影响你其他设置。

## 从源码运行 / 自己打包

需要 Windows + Python 3.11，并安装依赖：

```bat
pip install -r requirements.txt
```

其中 `pywin32` 用于直驱打印机，`PyMuPDF` 渲染页面，`windnd` 用于窗口拖放。

打包成绿色版（onedir 文件夹）：

```bat
pip install pyinstaller windnd
python build_exe.py            # 在 dist\双面打印助手\ 生成绿色版文件夹
```

> 建议在一个**只装了必要依赖的干净虚拟环境**里打包，否则 PyInstaller 会把无关的重型包（如 torch/cv2）一并打进去，
> 体积会从几十 MB 暴涨到几百 MB。本项目自带 `requirements.txt` 只列了必要包。
